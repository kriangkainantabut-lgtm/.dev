# Kriangkai Nantabut | Portfolio

เว็บพอร์ตโฟลิโอ IT Support & Backend API (ไทย / EN / 中文) พร้อมโหมดมืด/สว่าง และเอฟเฟกต์ขยายรูปเมื่อชี้เมาส์

Single-page portfolio (Thai / English / Chinese) with light/dark mode and hover-to-zoom images.
Plain HTML, CSS and JavaScript in one file. No build step.

## Files

| File | Description |
|------|-------------|
| `index.html` | The whole site (images are embedded) |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |

## Deploy on GitHub Pages

1. Create a new repository, e.g. `kriangkai-portfolio` (or `<username>.github.io` for a root URL).
2. Upload `index.html`, `.nojekyll` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. After a minute the site is live at `https://<username>.github.io/<repository>/`.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder.
